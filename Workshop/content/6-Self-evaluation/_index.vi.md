# Tự Đánh Giá Năng Lực (Self-Evaluation)

Đánh giá bản thân theo các tiêu chí tiêu chuẩn của chương trình **FCAJ Workforce Bootcamp 2026**:

| Tiêu chí | Mức độ | Nhận xét chi tiết & Minh chứng từ dự án |
| :--- | :---: | :--- |
| **1. Kiến thức chuyên môn** | **Tốt** | Nắm vững kiến trúc Full-Stack Web E-Commerce. Thành thạo lập trình Spring Boot 3 Java (Entities, JPA, Controllers, Services), Next.js 16 (App Router, React 19, TypeScript, Tailwind CSS v4) và triển khai dịch vụ AWS (RDS MySQL, S3, EC2, CloudWatch). |
| **2. Khả năng học hỏi** | **Tốt** | Chủ động tiếp thu các công nghệ tiên tiến như Next.js 16 App Router, Tailwind CSS v4 và các công cụ AWS Cloud Native để áp dụng trực tiếp vào sản phẩm thực tế. |
| **3. Tính chủ động** | **Tốt** | Hoàn thành tốt 100% các cột mốc công việc hàng tuần, chủ động xử lý các lỗi phát sinh như CORS, quản lý tồn kho và đồng bộ trạng thái giỏ hàng. |
| **4. Kỷ luật công việc** | **Tốt** | Chấp hành nghiêm túc quy định văn phòng AWS Vietnam / FCAJ, ghi nhận worklog báo cáo đúng tiến độ tuần từ Week 1 đến Week 12. |
| **5. Khả năng giao tiếp** | **Khá** | Trình bày giải pháp kỹ thuật mạch lạc, tham gia thảo luận kiến trúc hiệu quả với mentor. |
| **6. Khả năng Teamwork** | **Khá** | Phối hợp tốt với các thành viên trong dự án, tích cực hỗ trợ và lắng nghe phản hồi cải tiến sản phẩm. |
| **7. Giải quyết vấn đề** | **Tốt** | Xử lý triệt để các vấn đề phức tạp như tính toán chi phí đơn hàng, tự động phát sự kiện `OrderEvent`, đẩy media assets lên Amazon S3 và theo dõi log CloudWatch. |
| **8. Đóng góp cho dự án** | **Tốt** | Xây dựng thành công hệ thống E-Commerce Apple Store hoàn chỉnh có khả năng phát hành và vận hành thực tế trên đám mây AWS. |
