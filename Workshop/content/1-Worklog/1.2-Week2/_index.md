### Week 2 Objectives

* Learn about **Amazon S3** and the Object Storage model.
* Practice creating and managing **S3 Buckets and Objects**.
* Learn about access control and security in Amazon S3.
* Learn about **Amazon RDS** and managed relational databases on AWS.
* Practice connecting **EC2 to RDS**.
* Learn about **Public and Private Subnets** in AWS architecture.
* Learn about **NAT Gateways** and providing internet access to resources in a Private Subnet.
