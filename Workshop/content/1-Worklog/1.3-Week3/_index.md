### Week 3 Objectives

* Learn the fundamentals of **Docker**.
* Practice building **Docker Images and Containers**.
* Learn **Docker Compose** and how to run multiple Containers.
* Learn about **Amazon ECR** and managing Docker Images on AWS.
* Learn about **AWS Systems Manager** and Session Manager.
* Learn about **Amazon CloudWatch** and monitoring AWS resources.
* Practice deploying a Docker application on EC2.

### Week 3 Achievements

* Understood **Docker Images, Containers, Dockerfiles, and Docker Compose**.
* Learned to build and run **Docker Containers**.
* Learned to use Docker Compose to manage multiple Containers.
* Practiced **building, tagging, and pushing Docker Images to Amazon ECR**.
* Learned to manage EC2 with **AWS Systems Manager and Session Manager**.
* Understood the basic monitoring features of **Amazon CloudWatch**.
* Practiced deploying a Docker Container on **EC2** from a Docker Image stored in **ECR**.
* Built foundational knowledge for deploying the TechMart system on AWS.
