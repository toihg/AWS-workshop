# Sharing & Feedback

The FCAJ Bootcamp 2026 internship program provided a valuable learning and hands-on environment. During the internship, I gained extensive knowledge and experience in AWS cloud infrastructure. This knowledge helped me complete the process of building and deploying an E-Commerce system from the initial idea to its actual deployment on AWS, while also providing a foundation for my future career.

### Satisfaction Level
* **Overall Assessment:**
* The mentors were friendly, enthusiastic, and always willing to answer questions.
* The program provided a good balance between theory and practice, and the sharing sessions provided a lot of new and useful knowledge.

### Suggestions for Improvement
* Some content, such as the Highly Available Web Application Workshop, Database Migration with AWS Database Migration Service (DMS), and AWS Schema Conversion Tool (SCT), is currently experiencing errors, preventing learners from accessing the content.
