### Executive Summary

This internship report details the design, implementation, and deployment of a **Cloud-Native Apple E-Commerce Platform**:
- **Backend Service (`ecommerce`):** Built with Java 21 & Spring Boot 3, utilizing Spring Data JPA, MySQL DB, REST APIs for products, orders, authentication, and an automated email notification service.
- **Frontend Web App (`Frontend`):** Built with Next.js 16 (App Router), React 19, TypeScript, and Tailwind CSS v4. Features responsive UI, product filters (MacBook, iPhone, iPad, AirPods, Apple Watch), Client-side Cart Context, COD/Bank Transfer payment flows, real-time Order Event Timeline, and an Admin Dashboard.
- **Cloud Infrastructure (AWS):** Deployed on AWS using **Amazon S3** (media storage), **Amazon RDS MySQL** (cloud database), **Amazon EC2 / AWS App Runner** (hosting), and **Amazon CloudWatch** (monitoring & logs).
