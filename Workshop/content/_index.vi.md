### Tóm Tắt Dự Án Báo Cáo

Dự án báo cáo thực tập tập trung xây dựng nền tảng **Thương Mại Điện Tử Apple Store Cloud-Native** với kiến trúc Full-Stack hiện đại:
- **Backend Service (`ecommerce`):** Lập trình bằng Java 21 & Spring Boot 3, tích hợp Spring Data JPA, MySQL Database, cung cấp các RESTful APIs xử lý quản lý sản phẩm, tài khoản, giỏ hàng, tạo đơn hàng và dịch vụ tự động gửi email thông báo ([EmailNotificationService](file:///c:/Users/Toi%20Hoang/Code/ecommerce/src/main/java/com/ecommerce/service/EmailNotificationService.java)).
- **Frontend Web App (`Frontend`):** Phát triển bằng Next.js 16 (App Router), React 19, TypeScript và Tailwind CSS v4. Hỗ trợ giao diện responsive, bộ lọc sản phẩm theo danh mục (MacBook, iPhone, iPad, AirPods, Apple Watch), quản lý trạng thái giỏ hàng Client-Side (`cart-context.tsx`), quy trình thanh toán COD/Chuyển khoản ngân hàng, dòng thời gian theo dõi đơn hàng (`order-event-timeline.tsx`) và trang quản trị Admin.
- **Hạ Tầng Điện Toán Đám Mây (AWS):** Triển khai ứng dụng lên AWS sử dụng **Amazon S3** (Lưu trữ ảnh sản phẩm), **Amazon RDS MySQL** (Cơ sở dữ liệu đám mây), **Amazon EC2 / AWS App Runner** (Host ứng dụng Backend & Frontend), và **Amazon CloudWatch** (Giám sát chỉ số và nhật ký vận hành).
